# Introduktion til Sundhedsdata

An introduction to **data management and visualization in health economics** using Danish register data. Part of the MSc in Health Economics.

Over eight sessions you will build an analysis-ready dataset from Danish health registers, document and replicate your work, and explore and present the data through tables and figures.

Teaching is in Danish and English.

## Getting started

Before the first session, work through the installation guide:

- [`course_materials/lektion1/lektion1-installation.qmd`](course_materials/lektion1/lektion1-installation.qmd) — installing R, Positron, Git and the required R packages

It is also posted on itslearning as a PDF, which is the easier way to read it before you have cloned this repository.

Course materials are Quarto (`.qmd`) files. Open one in Positron and render it to read the finished document.

## Data

**The data is not in this repository.** Download the data files from itslearning and unzip them at the top level of this folder, so that the files land in `data/raw/` and `data/processed/`.
